# 卡密授权系统 —— 设计文档

> 目标：软件放网盘自由下载，**没卡密打不开**；一码一机；人工发卡；永久授权；不加壳。

---

## 一、总体流程

```
用户：网盘下载 → 双击 启动.exe → 出现「激活窗口」
        窗口显示本机【机器码】(如 9F3A-21C7-B8E0-4D55) + 卡密输入框
      ↓ 没卡密 → 进不去主界面
      ↓ 加你微信打赏 → 把机器码发你

你：  打开发卡器 → 粘贴机器码 → 生成卡密 → 微信发回

用户：把卡密粘进激活窗口 → 点「激活」→ 校验通过
      → 写入本地授权文件 license.dat → 进入主界面 → 永久可用

换机：新电脑显示新机器码 → 发你 → 你重新生成卡密 → 再次激活
```

## 二、技术选型

| 项目 | 决定 |
|---|---|
| 加密/签名 | **Ed25519**（Python `cryptography`，公钥验签 / 私钥签名） |
| 机器指纹 | 主板UUID + CPU ID + 系统盘序列号（**不取 MAC**） |
| 卡密格式 | `QWEN-XXXXX-XXXXX-XXXXX-XXXXX`（内嵌机器码摘要 + 签名片段） |
| 激活记忆 | `license.dat`（JSON + 签名），存 `APP_DIR`，下次启动免输 |
| 发卡器 | 独立小工具（`发卡器.py` + bat），**只给你**，内含私钥 |
| 客户端闸门 | 新增 `license.py`，`app.py` 的 `main()` 开头调用 |
| 加壳 | **不做** |

## 三、签名机制（核心）

- 用 **Ed25519 非对称密钥**：
  - **私钥** → 只在你手里（发卡器用），**绝不放进给用户的软件**
  - **公钥** → 内嵌在软件里（`license.py`），用于验签
- 卡密 = 机器码 + 你的签名
- 校验逻辑：
  1. 用户输入卡密 → 用公钥验签 → 确认"确实是你发的"
  2. 取出卡密里的机器码摘要 → 和本机指纹比对 → 一致才放行
- **别人自己编的卡密过不了验签**（没有你的私钥）；换个机器指纹对不上也过不了

### 密钥文件（只在你手里，不进发布包）
```
keys/private_key.pem   ← 发卡器用（保密！丢了就没法发卡）
keys/public_key.pem    ← 随软件发布
```

## 四、机器指纹算法

取稳定因子，容忍硬件小改动：
- 主板 UUID（Windows: `wmic csproduct get uuid` / CIM）
- CPU ProcessorId
- 系统盘（C:）卷序列号
- **不取 MAC**（网卡/驱动变化太频繁）

→ 拼接后 SHA-256 → 取前 16 字节 → 格式化成 `XXXX-XXXX-XXXX-XXXX`

## 五、卡密格式设计

```
QWEN-AAAA-BBBB-CCCC-DDDD
```
- `AAAA-BBBB` = 机器码摘要片段（8 hex）
- `CCCC-DDDD` = 签名片段（8 hex）
- 实际内部：base32( 机器码hash(8B) + 时间戳/序号(4B) + 签名(截断) ) → 便于人工搬运

> 具体编码实现时定稿（目标：人工可读、好念、够短、不可猜）。

## 十一、注意事项 ⚠️

- ⚠️ **`keys/private_key.pem` 绝不能进发布包 / 传网盘**（丢了就没法发卡，泄露了别人能造卡）
- ⚠️ 发布前检查：软件里**只有** `public_key.pem`，没有 `private_key.pem`
- ⚠️ 发布时**删掉** `license.dat`（别把你自己激活的带出去）
- ⚠️ 用户重装系统 / 换主板 / 换CPU / 系统盘格式化 → 指纹变 → 需重新激活（正常）
- ⚠️ 卡密较长（144 字符）→ 让用户**复制粘贴**，别手打
- ⚠️ 指纹取的是 **UUID + CPU ID + C盘卷序列号**，不取 MAC（防误伤）

## 十二、卡密格式（技术细节）

```
card = Base32( payload(8字节) + Ed25519签名(64字节) )  → 分组4字符
payload = 指纹前6字节 + 序号2字节
```
- 验签用公钥（确认是你签发的）
- 指纹前 6 字节与本机比对（确认是本机）
- 截断/篡改 → 验签失败

# 发卡器使用说明

> 这个文件夹**只给你自己用**，**绝对不要**发给用户或传网盘。

## 怎么用

1. 双击 **`发卡器.bat`**
2. 弹出窗口
3. 把用户微信发来的**机器码**粘进第一个框（形如 `MIGC-UM7G-RBQE-S43P`）
4. 点 **「生成卡密」** → 卡密自动生成并**复制到剪贴板**
5. 粘贴到微信发给用户

## 换机时

用户换电脑 → 他新电脑上显示**新的机器码** → 发你 → 你**再生成一张新卡**发他。

## 重要提醒

- ⚠️ `keys\private_key.pem` 是**签名的私钥**，就相当于你的"印章"。
  - **丢了** → 以后没法再发卡（老的卡还能用，新的发不了）
  - **泄露** → 别人能自己造卡白嫖你的软件
  - **请单独备份**（比如存到你的微信收藏 / 邮箱 / U盘）
- ⚠️ 整个「发卡器」文件夹**不要**跟着软件一起发布。

## 安全备份建议

把这两样单独存一份到别的地方（网盘私人空间/邮箱/U盘）：
- `keys\private_key.pem`
- 记清楚：这个私钥对应软件里内嵌的公钥（已固定，不用管）

## 目录说明

| 文件 | 作用 |
|---|---|
| `发卡器.bat` | 双击启动 |
| `issue_card.py` | 发卡逻辑 + 界面 |
| `keys\private_key.pem` | 签名私钥（命根子） |
| `keys\public_key.pem` | 公钥副本（备用，软件里也有一份） |
| `py\` | 自带的小型 Python 运行环境（约 44MB，不用装任何东西） |
